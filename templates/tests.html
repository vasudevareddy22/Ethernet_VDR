📝 Testing Notes

  • All test cases executed using Flask's built-in test_client() + live SQLite database.
  • Integration test script (integration_test.py) runs 14 automated assertions covering TC01–TC10.
  • TC11 (chart rendering) verified manually in browser — Chart.js renders client-side from server-provided data attributes.
  • TC12 (logout) verified via HTTP redirect check and subsequent protected-route access attempt.
  • Demo data: 3 medications (Paracetamol, Vitamin D, Calcium) with 7 days of pre-seeded adherence history for a non-empty dashboard.
  • Technology: Python 3, Flask 2.x, SQLite3, Werkzeug, Chart.js 4.x, HTML5, CSS3.
  • Disclaimer: This is a student software prototype for academic demonstration only. Not for clinical use.
