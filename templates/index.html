Low False Positive Rate (2.8%)

Only 2.8% of legitimate business traffic was incorrectly flagged, protecting regular operations from interruption.

Zero-Day Attack Generalization

KDDTest+ includes 17 novel attack categories not present in the training set (e.g., mscan, saint), providing genuine out-of-distribution evaluation.

Supervised Random Forest Pipeline
  • AlgorithmRandomForestClassifier (100 Trees)
  • Categorical EncodingOrdinalEncoder (unknown_value=-1)
  • Numerical ScalingStandardScaler (Zero-mean, Unit-variance)
  • Class WeightBalanced (compensates class imbalance)
  • Train Split Size125,973 network records
  • Test Split Size22,544 held-out records
Unsupervised Isolation Forest Engine
  • AlgorithmIsolationForest (100 Estimators)
  • Contamination Ratio0.50 (configured threshold)
  • Metric TypeDecision Function (higher = normal, <0 = anomaly)
  • Pre-scalingShared StandardScaler Offsets
  • RoleComplementary zero-day anomaly scoring
  • IntegrityScores not conflated with attack probability
